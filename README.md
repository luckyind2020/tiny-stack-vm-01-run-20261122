A tiny stack VM for make.fun's ISA. Node 22 runs `node main.ts`: it reads `/input/<id>/program.bin` and `input.bin` and writes `/output/<id>/stdout.bin` and `exit.txt` — the bytes the program wrote and the exit code it ended with.
